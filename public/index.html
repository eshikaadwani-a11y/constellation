The laboratory

Not a dashboard. An engineering instrument.

Constellation pairs a deterministic discrete-event simulation core with a custom topology renderer and a full observability stack — so you can reason about behaviour you would normally only read about.

◈

Deterministic engine

A virtual-clock, event-driven core. Every run is a pure function of one seed, so any outcome can be reproduced and replayed exactly.

⊹

Live topology

A hand-built graph engine renders nodes, links, and in-flight messages at 60fps — no framework, no black box.

⚡

Real protocols

Raft consensus, gossip, vector clocks, and consistent hashing — implemented for real, not faked, and verified by tests.

🜂

Chaos engineering

Partition the network, crash leaders, add latency and packet loss, then watch the protocol fight to stay correct.

◷

Time-travel observability

Metrics, structured logs, and distributed traces stream from the engine. Scrub the timeline to any moment and inspect every event.

✦

Explains itself

A built-in tutor narrates why the system behaved as it did — turning every simulation into a lesson you can actually feel.

Under the hood

A pure, isomorphic core you can read

The same TypeScript that drives the browser runs the test suite in Node. No hidden state, no wall-clock racing — just a scheduler, a seeded RNG, and a network you control.

constellation.ts 
// Spin up a five-node Raft cluster and watch it elect a leader.
const sim = new Simulation({ seed: 42 });
const cluster = raftCluster(sim, { nodes: 5 });

// Inject a network partition at t = 2s, heal it at t = 6s.
sim.chaos.partition(["n1", "n2"], { at: 2000, until: 6000 });

sim.run({ until: 10000 });

console.log(cluster.leader());  // → "n4" (term 3)
